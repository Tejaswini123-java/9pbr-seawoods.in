# Adani 9 PBR Seawoods – Premium Residential Project

A responsive real estate landing page showcasing **Adani 9 PBR**, a premium residential development in Seawoods, Navi Mumbai.

The website provides project information, apartment configurations, floor plans, amenities, location connectivity, image galleries, and enquiry forms.

## 🌐 Project Details

- **Project Name:** Adani 9 PBR
- **Location:** Seawoods, Nerul, Navi Mumbai
- **Developer:** Adani Realty
- **Property Type:** Premium Residential Apartments
- **Configurations:** 3 BHK Apartments and Signature Penthouses

## ✨ Website Features

- Responsive design for desktop, tablet, and mobile.
- Project overview and highlights.
- Apartment configurations and pricing information.
- Detailed floor plans.
- Master plan and project layout.
- Amenities and lifestyle features.
- Image gallery.
- Location and connectivity details.
- Enquiry and lead generation forms.
- Thank-you page after enquiry submission.
- Privacy policy page.
- WhatsApp and contact options.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- PHPMailer
- SMTP
